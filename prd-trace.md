## 2. Contradictions with the PRD

1. ~~**Price shows in results by default.**~~ Fixed: price is now off by default (NFR-3).
2. ~~**Stock shows in results by default.**~~ Fixed: stock no longer appears in results (FR-8).
3. ~~**Add room and rename are separate, and room type isn't visible.**~~ Fixed: one add-or-rename form, and the type shows in the room bar (FR-21). The "Adding to" list still shows line counts, not types; FR-21 is met by the room bar.
4. **Kit components show as soon as a kit is added.** Technical discovery: "Kits: components don't exist until the quote round-trips to M3". The PRD's Design section acknowledges this ("the prototype's kit expansion follows the bundle convention"). Proposal: label the components as a preview until save, or add this to Design questions.
5. **"Often added" checks only the same room.** The PRD says "a part already on the quote isn't offered again", but v2's "Often added" checks only the same room for a part already added. Required parts are counted quote-wide, so they're fine. (Resolved Nov 5: the PRD's FR-14 now says a skipped required part is a "to check" warning, not a blocker, unless Kelli decides otherwise, which matches v2's "To check" placement, `crWarn`.)
6. **Status codes appear next to the reasons.** Resolved Nov 5: Kelli wants the status shown, as today's results do, so the PRD (FR-4) now allows it beside the sentence and the prototype shows it on every row.
